AI Lab

Building with AI, early

Every experiment, shown the way I debug it: as a trace of each step from question to answer. The runs below are sample inputs.

trace · tone-tunersample runsuccess

Tone Tuner

Claude wrapped in six focused tools instead of one chat box, so each task gets its own prompt and its own screen.

  1. input

    hey can we push the meeting, something came up · tone: formal

  2. prompt one per tool

    The Rephrase tool builds its own prompt for the chosen tone

  3. llm Claude, via a server function

    Rewrite in a formal register and keep the meaning; the API key never reaches the browser

  4. output

    Could we reschedule our meeting? Something unexpected has come up.

trace · hungerbridge-safetysample runsuccess

HungerBridge food-safety check

Every new donation gets a quick AI review on the server. If the pickup window is risky, everyone sees a short warning on the food card.

  1. input

    Chicken curry and rice · non-veg · pickup in 2.5 hours

  2. server Express route

    Work out the hours until pickup and build a rules prompt

  3. llm Claude Haiku · 60 tokens

    Flag under 2 hours as urgent, non-veg under 3 hours as risky, otherwise answer null

  4. guard never blocks

    If the API fails or says null, the post still goes live, just without a note

  5. output

    Non-veg with a short window, pick up quickly. shown on the card
